# US-013. Extract the RP+GA nucleus fragment for one row

As an engineer, I want a function that reduces one word's RP/GA cells down to the vowel nucleus corresponding to a target GA pattern, so that [[US-007]]'s dominance tally compares like-for-like fragments instead of whole-word transcriptions.

## background
Whole-word RP transcriptions almost never collide across different words, so tallying dominance on full `:rp` cells (as an earlier draft of [[US-007]] did) makes "dominance" trivially 100%-per-word and the proportion meaningless. The fix is to reduce each row to just the **nucleus** — the vowel (plus any rhotic `ɹ` that colors it) — stripped of onset/coda consonants and stress marks, aligned by syllable position between the row's RP and GA cells.

Example: `target-ga "/ɑɹ/"`, row `{:word "gnarly" :rp "/ˈnɑː.li/" :ga "/ˈnɑɹ.li/"}`:
1. Strip slashes: `rp "ˈnɑː.li"`, `ga "ˈnɑɹ.li"`, `target-ga "ɑɹ"`.
2. `:ga` has one variant; it contains `"ɑɹ"`.
3. Split on `.` → GA segments `["ˈnɑɹ" "li"]`; `"ɑɹ"` is in segment 0 → **GA segment** `"ˈnɑɹ"`.
4. `:rp` has one variant, same syllable count (2) as the GA variant. Split on `.` → RP segments `["ˈnɑː" "li"]`; take segment 0 (same index as the GA segment) → **RP segment** `"ˈnɑː"`.
5. Drop leading stress marks (`ˈ`/`ˌ`) from each segment, then trim leading/trailing characters in the consonant set `#{p b t d k ɡ tʃ dʒ f v θ ð s z ʃ ʒ h m n ŋ l w j}` — **`ɹ` is deliberately excluded** from this set so a rhotic vowel like `ɑɹ` isn't stripped as a coda.
6. `"ˈnɑɹ"` → drop stress → `"nɑɹ"` → trim leading `n` (onset consonant) → `"ɑɹ"`. `"ˈnɑː"` → `"nɑː"` → `"ɑː"`.
7. Result: `["ɑː" "ɑɹ"]`.

## Protocol
`nemo-words.pairs/extract-nucleus` — a pure function `[rp ga target-ga] -> [rp-nucleus ga-nucleus]` or `nil`, operating on one row's raw (possibly comma-joined) `:rp`/`:ga` cell text plus the `target-ga` substring that matched it. Unit-tested directly on fixture cell strings — no CLI, no subprocess. Called once per row by [[US-007]]'s `dominant-pair`, which discards `nil` results (rows contributing nothing to its tally) and tallies the rest.

Variant selection, when a cell holds comma-joined variants (per [[US-001]]'s data-reality note — RP/GA variants are not positionally paired):
- From `:ga`, pick the **first** variant containing `target-ga` as a substring.
- From `:rp`, pick the **first** variant whose syllable count (segments split on `.`) equals the chosen GA variant's syllable count. If none matches, return `nil`.
