# US-007. Find the dominant RP+GA pairing for a missing GA combination
As an engineer, I want a function that ranks RP+GA pairings for a given GA IPA, so that I know which RP+GA pair defines the new set.

## background
Search for the target GA combination, e.g. `/ɑɹ/`, across the word, RP IPA, GA IPA triples and collect every match, e.g. `/ˈnɑː.li/` (RP), `/ˈnɑɹ.li/` (GA). From the matches, extract the corresponding RP vowel combination for each word, then compute the proportion of each distinct RP+GA pairing across all matches. Only the highest-percentage RP+GA pair is kept as the new set's defining pair.

## Protocol
`nemo-words.pairs/dominant-pair` — a pure function `[triples] -> [rp ga]`, taking the seq of `{:word :rp :ga}` rows from `ipa/lookup-rows` (filtered to the target GA) and returning the single highest-percentage RP+GA pair. Unit-tested directly on fixture triples — no CLI, no subprocess; called in-process from [[US-006]]'s `extend-set`.

## Acceptance Criteria

```gherkin
Scenario: One RP pairing clearly dominates
  Given triples where RP "/ˈnɑː.li/" pairs with the target GA in 8 of 10 matches
  And a different RP pairs with it in the other 2
  When dominant-pair is called
  Then it returns ["/ˈnɑː.li/" <the target GA>]

Scenario: Exact tie between two RP pairings
  Given triples split evenly 5/5 between two distinct RP pairings for the target GA
  When dominant-pair is called
  Then it returns whichever of the two pairings occurs first in the input triples (stable on input order, not on pairing content — so re-ordering the input can change the result, but a fixed input always gives the same output)

Scenario: Only one RP pairing exists
  Given all triples share the same RP for the target GA
  When dominant-pair is called
  Then it returns that single pairing with 100% dominance

Scenario: No triples for the target GA
  Given an empty seq of triples
  When dominant-pair is called
  Then it returns nil rather than a bogus pair or throwing (it's a pure query function — [[US-006]]'s `extend-set` is the one that decides an empty result is reportable, see its "No matches for the given GA at all" scenario)
```
