# US-008. select and rank the example words for a new set
As an engineer, I want to rank the matched words by Google frequency and take the top 60 (plus the keyword), so that the new set has the same word budget as an existing set.

## background
Once the winning RP+GA pair is chosen (US-007), reuse the US-003 frequency CLI to rank its matching words and keep the top 60 + 1, mirroring how US-004 builds an existing set's word list.

**Superseded:** the ranking step is just [US-010](US-010.md) `rank-top-n 60`, the same filter [US-004](US-004.md) uses — no separate implementation needed. Kept here for traceability only.

**Correction:** this story's own title/background said "top 60 + 1" (61), implying the keyword is picked from a pool one larger than what gets saved. [US-006](US-006.md)'s actual composition code calls `top-n :freq 60` and then picks the keyword *from that same 60* — there is no 61st word. [US-009](US-009.md) has been corrected to match: 60, not 61.
