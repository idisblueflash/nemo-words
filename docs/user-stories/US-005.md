# US-005. Use the Lexical Sets
As an AI agent, I want to fetch custom example words, so that I can compose a mnemonic story later.

## background
A dedicated CLI pick-example-words-by-ipa will search examples by IPA. And a list of words return for AI to handle.

## Protocol
`pick-example-words-by-ipa <IPA query>` is a thin `core.clj` subcommand — it's the one story with a genuine external consumer (the AI agent), so it stays a real CLI. It reads `lexical-sets.edn` (built by [[US-004]]/[[US-006]]), matches the query against **either** a set's RP or its GA IPA (substring match, same semantics as [[US-001]]'s `{:rp ipa}` / `{:ga ipa}` opts — an agent querying with only one accent's IPA should still hit the set), and writes stdout — one word per line.

If more than one set matches (a query IPA can be a substring of several sets' RP/GA), it writes the **union of all matching sets' word lists**, deduped, in stable order (first set's words first) — never just the first match, since silently dropping matches would be a worse surprise for the AI-agent consumer than a longer list.

## Acceptance Criteria

```gherkin
Scenario: IPA matches exactly one set
  Given lexical-sets.edn has one entry whose IPA is "/ɜː/"
  When I run `pick-example-words-by-ipa /ɜː/`
  Then stdout lists that entry's words, one per line
  And nothing else is printed

Scenario: IPA matches more than one set
  Given lexical-sets.edn has two entries whose RP or GA both contain the queried IPA
  When I run pick-example-words-by-ipa with that query
  Then stdout lists the deduped union of both entries' words, one per line
  And the first entry's words come before the second's

Scenario: IPA matches no set
  Given no entry in lexical-sets.edn matches the queried IPA
  When I run pick-example-words-by-ipa with that query
  Then stdout is empty
  And the process exits 0

Scenario: lexical-sets.edn does not exist yet
  Given no lexical-sets.edn file has been built
  When I run pick-example-words-by-ipa
  Then it reports a clear "no lexical sets built yet" message
  And exits non-zero
```
