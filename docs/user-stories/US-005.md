# US-005. Use the Lexical Sets
As an AI agent, I want to fetch custom example words, so that I can take a quick view about this row of RP/GA pair.

## background
A dedicated CLI pick-example-words-by-ipa will search examples by IPA. And a list of entries return for AI to handle.

## Protocol
`pick-example-words-by-ipa <IPA query>` is a thin `core.clj` subcommand — it's the one story with a genuine external consumer (the AI agent), so it stays a real CLI. It reads `lexical-sets.edn` (built by [US-004](US-004.md)/[US-006](US-006.md)), matches the query against a set's **GA** IPA only (substring match, same semantics as [US-001](US-001.md)'s `{:ga ipa}` opt — learners focus on GA, so RP is not queried here), and writes stdout as **EDN**: a vector of `{:keyword :rp :ga :words}` maps, one per matching set, in stable order (the order they appear in `lexical-sets.edn`).

If more than one set matches (a query IPA can be a substring of several sets' GA), the vector has one entry per matching set — no cross-set dedup, since each entry keeps its own `:rp`/`:ga` context and words stay grouped under the set they belong to. Never just the first match, since silently dropping matches would be a worse surprise for the AI-agent consumer than a longer vector.

For example, querying `/ə/` against `lettER` (`:ga "əɹ"`, words `paper metre calendar stupor succour martyr`) and `commA` (`:ga "ə"`, words `catalpa quota vodka`) — both GA cells contain `/ə/` — prints:

```edn
[{:keyword "lettER" :rp "ə" :ga "əɹ" :words ["paper" "metre" "calendar" "stupor" "succour" "martyr"]}
 {:keyword "commA" :rp "ə" :ga "ə" :words ["catalpa" "quota" "vodka"]}]
```

`lettER`'s entry comes first (stable order), then `commA`'s.

When no set matches, stdout is an empty EDN vector `[]` (not blank stdout — `edn/read-string` on an empty string errors, so the consumer always gets valid EDN to parse), and the process exits 0.

## Acceptance Criteria

```gherkin
Scenario: IPA matches exactly one set
  Given lexical-sets.edn has one entry whose GA is "/ɜr/"
  When I run `pick-example-words-by-ipa /ɜr/`
  Then stdout is an EDN vector with that one entry's {:keyword :rp :ga :words}
  And nothing else is printed

Scenario: IPA matches more than one set
  Given lexical-sets.edn has two entries whose GA both contain the queried IPA
  When I run pick-example-words-by-ipa with that query
  Then stdout is an EDN vector with one map per matching entry, each keeping its own :keyword/:rp/:ga/:words
  And the first entry appears before the second, in lexical-sets.edn's order

Scenario: IPA matches no set
  Given no entry in lexical-sets.edn matches the queried IPA
  When I run pick-example-words-by-ipa with that query
  Then stdout is the empty EDN vector "[]"
  And the process exits 0

Scenario: lexical-sets.edn does not exist yet
  Given no lexical-sets.edn file has been built
  When I run pick-example-words-by-ipa
  Then it reports a clear "no lexical sets built yet" message
  And exits non-zero
```
