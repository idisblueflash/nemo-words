# Bug reports

`backlog:buzz` (the `backlog` plugin, via `/backlog:implement`) files one
`bug-NNN-<slug>.md` here per bug `backlog:qa` flags against a backlog item
(`original_story: <ID>`). Numbering shares one counter with the legacy reports in
`docs/user-stories/bug-*.md` — see `.claude/rules/build.md`. Kept outside `items/` because the `backlog` plugin treats
every file there as an epic/story/spike/enabler.
