# C-032 Closed keyword

**Meaning:** The keyword that the stressed chunk gets from its closed chunk. It is the most common word that sounds exactly like the closed chunk. It also passes these filters: frequency 5e-7 or more, 3 or more letters, not the headword, not a function word, and not a word that the headword is an inflection of. When a closed keyword exists, it is used instead of the open chunk's exact keyword and instead of a rhyme.
**Example:** penalty /ˈpɛ.nəl.ti/ → closed chunk /pɛn/ → "pen" (not the rhyme "ye"). era → "air" (not "eh"). sweating gets no closed keyword "sweat", because sweating is an inflection of sweat.
**Not the same as:** a closed chunk (C-026), which is the sound /pɛn/ and not the word "pen". Also not a rhyme anchor (C-011), which matches only the rime of one chunk.
