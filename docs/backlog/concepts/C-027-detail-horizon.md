# C-027 Detail horizon

**Meaning:** The top N open stories in the BACKLOG.md ranking. N is the `Ready horizon` setting, and it is 5 now. Only these stories get acceptance criteria and a logic sketch. The stories below them stay `idea`, because the plan can still change.
**Example:** Today the top 5 open items (US-060, US-059, US-061, US-042 and US-043) are all `idea`. Thus 0 stories are `ready` to build.
**Not the same as:** the WIP limit (3), which is the highest number of items in progress at the same time.
