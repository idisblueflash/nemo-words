# C-041 Tuning set

**Meaning:** The words that a spike uses to set its weights and rules. The other words are the measure set. The measure set runs one time, after nothing changes any more, and the spike's rates come from it.
**Example:** SP-066 draws 20 of its 82 words as its tuning set, with 4 or 5 SP-064 hits among them, and measures on the other 62.
**Not the same as:** the chance rate, which is a baseline to compare a rate with, not a set of words.
