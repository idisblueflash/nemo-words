# C-044 Binomial test against chance

**Meaning:** A test that asks whether random picks could reach a rate this high by luck. It gives p, the probability that random picks do as well or better. A p below 0.05 means that the pick beats the chance rate (1/9 for exact, 3/9 for in-three).
**Example:** For SP-064, 13 of 62 exact against 1/9 gives p = 0.017, so it beats chance. 26 of 62 in-three against 3/9 gives p = 0.098, so it does not clearly beat chance.
**Not the same as:** the go bar. A small p shows only that the pick is better than random, not that it is good enough to use.
