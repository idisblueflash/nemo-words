# C-034 Must-see list

**Meaning:** The objects of a story that a picture must show, each with its adjective. A name used as a sound anchor gives the person or thing that carries it as an item, and the name itself as a name sign. The list also names its main subject (C-045), when the story has one. The gate checks only the item names: a grid cell that hides an item is out of the pick. The adjectives count only toward the state part of must-see clarity (C-046).
**Example:** corncob's story "Campers roast corn, then toss the bare cob." gives `campers`, `roasting corn`, `bare cob`; ventilator's "Nurse Venice …" gives the item `nurse` and the name sign "Venice".
**Not the same as:** the pivot words in the mnemonic log, which also hold words you can't see (`later`, `white`, `cancerous`).
