# C-034 Must-see list

**Meaning:** The objects of a story that a picture must show, each with its adjective. A name used as a sound anchor becomes its visible sign. The gate checks only the item names: a grid cell that hides an item is out of the pick. The adjectives count only toward the clarity score.
**Example:** corncob's story "Campers roast corn, then toss the bare cob." gives `campers`, `roasting corn`, `bare cob`; ventilator's "Nurse Venice …" gives `a nametag that reads Venice`.
**Not the same as:** the pivot words in the mnemonic log, which also hold words you can't see (`later`, `white`, `cancerous`).
