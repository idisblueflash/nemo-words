# C-003 Sound anchor

**Meaning:** A common word whose GA IPA is exactly the same as one chunk's IPA. The story uses it so that Flash hears that chunk. A chunk with no exact match has no anchor and is taught by the IPA line.
**Example:** germane /dʒɝ.ˈmeɪn/: the chunk /meɪn/ gets the anchor "main". The chunk /dʒɝ/ has none.
**Not the same as:** a rhyme anchor, which matches only the rime of the stressed chunk; pivot words, which are the words in the sentence that carry the anchors.
