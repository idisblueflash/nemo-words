# C-022 Canonical NOAD IPA

**Meaning:** The one US IPA format that E07 takes from NOAD. A sound in brackets stays and only the brackets go, but `(h)` before `w` is dropped. When NOAD gives more than one US IPA, the first one is used.
**Example:** NOAD's raw `(h)wɪtʃ` becomes `wɪtʃ`.
**Not the same as:** the CMU-based GA IPA from `nemo-words ipa-lookup`, which the pipeline still uses today.
