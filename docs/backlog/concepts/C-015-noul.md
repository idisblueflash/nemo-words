# C-015 Noul

**Meaning:** One yes/no question that Jev answers with the probability of yes. A Noul passes at p 0.5 or more, unless a rule sets a different cut-off.
**Example:** "Is the whole sentence in one setting?" is one of the eight split-out Nouls for scene coherence.
**Not the same as:** a Score question, which Jev answers on three levels (0–2, shown as 1–3).
