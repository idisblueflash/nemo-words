# C-039 Axis weight

**Meaning:** A number that code multiplies one score axis by before it adds the axes to a total. A larger weight means that the axis counts more in the pick. The weights are set on the tuning words and are not changed for the measured words.
**Example:** SP-064 uses the weights 3 × plausible + 1 × vivid + 3 × must-see clarity. Cell 4 of `aisle` has plausible 2.94, vivid 2.53 and clarity 2.14, so its total is 3 × 2.94 + 1 × 2.53 + 3 × 2.14 = 17.77.
**Not the same as:** the margin signal (C-036). The margin is the gap between two totals after the weights are applied.
