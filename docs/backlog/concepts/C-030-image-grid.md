# C-030 Image grid

**Meaning:** A 3×3 sheet of 9 candidate pictures for one story. `_vivian` makes it. Flash, or later the auto-pick, chooses one cell, and `crop-grid-cell.sh` cuts that cell out as the card's image.
**Example:** `images/mnemonic/aisle.grid.png` → cell picked → `images/mnemonic/aisle.png`.
**Not the same as:** a comic, which is 3–4 cells from one or more grids, put together 2×2.
