# C-047 Actor

**Meaning:** The person who does a story's action when the story doesn't name that person. An actor can be the main subject (C-045), but it is never a must-see item, so the gate never checks it. A cell that doesn't show the actor stays in, and its view part gets the lowest level.
**Example:** sweep's story "Swing deep into the corner; grab the broom." names no person, but a person grabs the broom. The main subject is the actor, "person who grabs the broom": the woman in the grid.
**Not the same as:** a name anchor's carrier, such as the nurse (see C-043 Name sign), which the story names and which is a must-see item.
