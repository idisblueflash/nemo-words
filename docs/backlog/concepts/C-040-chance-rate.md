# C-040 Chance rate

**Meaning:** The rate that a pick gets if it chooses a cell or a story at random. A spike report shows it next to the real rate. A pick only has value if its rate is clearly higher than the chance rate.
**Example:** A grid has 9 cells, so the chance rate is 1/9 = 11% for exact and 3/9 = 33% for in three. SP-064's 21% exact is better than chance, but it is worse than the always-cell-1 rule (39%).
**Not the same as:** the always-cell-1 rule. That rule is a second baseline, and it is harder to beat than chance because Flash picks cell 1 for 34% of words. It is also not the 50/50 draw in US-051, which puts a word in an arm and does not measure a pick.
