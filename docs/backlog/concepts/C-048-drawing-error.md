# C-048 Drawing error

**Meaning:** An object that a grid cell draws wrong: it floats, it looks pasted on, or it breaks the lines of the wall or floor. An object that the story shows as broken or crooked on purpose is not a drawing error. An object that the cell's edge cuts off is not one either. Jev sees the drawing errors and gives plausible a lower score for them.
**Example:** in anomaly cell 7, the tilted orange tile sits on top of the wall's grout lines and doesn't fit the grid of tiles.
**Not the same as:** a must-see item in the wrong state (a cob that isn't bare yet), which lowers the state part of must-see clarity (C-050), not plausible.
