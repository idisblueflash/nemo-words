# C-014 Primary sense

**Meaning:** The one meaning of the word that the card teaches, written as one word. `define` chooses it today. Every story must use this word (or a form of it), so that the card does not teach a rare meaning.
**Example:** For trial, the sense is "legal — a court deciding guilt or innocence", not "a test run".
**Not the same as:** the gloss, which is the short meaning line shown on the card.
