# C-008 Hard gate

**Meaning:** A rule in code that every story must pass before Jev sees it. The story has no headword, 10 words or fewer, the sense word, pivots in chunk order, and anchors with exact IPA.
**Example:** A candidate for `concede` that says "conceded" fails with `headword: conceded`.
**Not the same as:** a judgment gate, which Jev decides, such as vividness or animal harm.
