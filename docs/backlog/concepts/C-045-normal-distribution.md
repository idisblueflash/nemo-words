# C-045 Normal distribution

**Meaning:** The bell curve. Suppose you measure a rate on many word sets of the same size. The measured rates spread around the true rate in this shape. 95% of them fall within 1.96 standard errors of the center, so z = 1.96 is the value for 95% certainty.
**Example:** The Wilson interval for SP-064 (13 of 62 exact) uses z = 1.96 and gives 13% to 33%. With z = 2.576 (99% certainty) the same data gives 11% to 37%, a range that is wider than the 95% range.
**Not the same as:** the binomial distribution that the binomial test against chance (C-044) uses. That test counts the exact chances of each number of hits. It does not use the bell curve, which is only an approximation.
