# C-009 Route

**Meaning:** The decision about which path a word takes. `general` gets a story card. `word-part` goes to `_etta_mology`, which breaks it into Greek/Latin parts. `ambiguous` is sent to Jev to decide.
**Example:** `nephrectomy` routes word-part. `wary` is ambiguous because of a weak `-ary` match, and Jev routes it general.
**Not the same as:** an arm, which splits words that are already routed general into story cards and definition-only cards.
