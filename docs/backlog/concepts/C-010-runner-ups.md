# C-010 Runner-ups

**Meaning:** The story candidates that were not picked, each with its reject reasons. They are saved as one line per word in `data/mnemonics/alternates.jsonl`, so that Flash can swap one in later.
**Example:** Four of the five drafted stories for `wary` go to `alternates.jsonl`. US-031 offers only the ones with no reject reasons.
