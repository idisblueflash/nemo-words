# C-046 Open short-vowel chunk

**Meaning:** A stressed chunk that ends in a short vowel /ɪ ɛ æ ʌ ʊ/, so its rime is only that vowel. Only weak words rhyme with it (ye, yeah, des, huh, ke, ca, sta), so it gets no rhyme anchor.
**Example:** tacit is /ˈtæ.sɪt/. The stressed chunk /tæ/ is an open short-vowel chunk. It used to get the rhyme "yeah"; now it gets none.
**Not the same as:** a closed chunk, which is the same chunk plus the first consonant of the next chunk (/pɛ/ → /pɛn/ "pen"). The closed chunk is tried first.
