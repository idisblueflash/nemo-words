# C-031 Word rhyme

**Meaning:** A fallback anchor for a word whose stressed chunk has no other anchor. It is a common word that sounds the same as the headword from the stressed vowel to the end of the word, with a different start of its stressed syllable. It can have more than one syllable. It covers the stressed chunk and every chunk after it.
**Example:** durable /ˈdʊ.ɹə.bəl/ → "incurable" (both end in /ʊɹəbəl/); bulge → "indulge".
**Not the same as:** a rhyme anchor, which matches the rime of one chunk and has one syllable.
