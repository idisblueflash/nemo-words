# C-018 Card file

**Meaning:** The file `anki/reading-room-terms.txt`, with one row per card: `Front\tBack\tImage\tIPA\tGloss\tDeck\tTags`. `anki-sync.js` pushes rows from it into Anki. Whole-word cards and word-part rows are both in it.
**Example:** `trial\tThe court tried a dull case, weighing his guilt.\ttrial.png\tˈtraɪ.əl\ta formal court hearing, or a test run`
**Not the same as:** the mnemonic log, which holds the structured record behind each story.
