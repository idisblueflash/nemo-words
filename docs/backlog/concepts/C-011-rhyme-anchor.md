# C-011 Rhyme anchor

**Meaning:** A fallback anchor for the stressed chunk when it has no exact sound anchor. It is a common one-syllable word with the same rime (vowel plus end sound), a different start, and not a function word.
**Example:** drown /dɹaʊn/ → "down"; critique's /tik/ → "speak".
**Not the same as:** a sound anchor, which must match the whole chunk exactly; a split or shifted chunk (US-050), such as vapor → vape/per.
