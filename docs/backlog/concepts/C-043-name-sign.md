# C-043 Name sign

**Meaning:** The name of a name anchor, as text that the picture should show, for example "Venice" on a nametag. The person or thing that carries it is the must-see item. A name that can't be read lowers must-see clarity, but it never takes a cell out of the pick.
**Example:** ventilator's story "Nurse Venice returns later; …" gives the must-see item `nurse` and the name sign `Venice`. In cell 1 the nametag is too small to read, so clarity is at the middle level at most, but the cell is still scored.
**Not the same as:** a must-see item, which the gate checks; the gate never checks a name sign.
