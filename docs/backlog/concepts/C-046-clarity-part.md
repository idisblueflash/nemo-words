# C-046 Clarity part

**Meaning:** One thing that must-see clarity checks, with its own Jev question: completeness, size, state, name sign or main-subject view. The name sign counts only for a name anchor, and the view only when the story has a main subject. Must-see clarity is the mean of the parts that count, so one part can't pull the whole score down.
**Example:** surgeon cell 1 has completeness 3, size 2 (a small headlamp), state 3 and view 3, so its clarity is (3 + 2 + 3 + 3) / 4 = 2.75.
**Not the same as:** an axis (C-039). Each axis has its own weight in the total; the clarity parts have no weights of their own.
