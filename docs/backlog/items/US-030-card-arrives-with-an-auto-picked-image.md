# US-030 The card arrives with an auto-picked image

As Flash, I want the image cropped from the auto-picked grid cell and attached to the card, so that the card has its picture without me picking one.

**Pick rule (from US-028 refinement):** Jev judges each cell's description against the story: one cell per grid row, then the best of those three.
