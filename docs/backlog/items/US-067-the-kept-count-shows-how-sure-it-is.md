# US-067 The kept count shows how sure it is

As Flash, I want the kept count to show the Wilson interval of its kept rate, so that I don't read "meets E01's 70% target" on 20 words as sure when the true rate could be about 50% (14 of 20 has a range of 48% – 85%).
